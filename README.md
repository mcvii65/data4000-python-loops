# DATA 4000: Python with AI (Loops)

This repository contains 10 beginner-to-intermediate Python exercises covering loops, conditionals, functions, dictionaries, and simple simulations.

Files included:
- checkout.py
- survey.py
- expenses.py
- commissions.py
- portfolio.py
- loan_simulator.py
- supply_chain.py
- loyalty_tiers.py
- growth_projection.py
- pitch_chart.py

Run each script individually with Python 3, for example:

python3 checkout.py
